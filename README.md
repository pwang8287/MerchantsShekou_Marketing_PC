# 招商蛇口客户营销分析 PC 端数据看板

Vue 3 + TypeScript + Vite 本地前端项目。营销分析覆盖营销经营、客户转化和营销效率；多维分析覆盖指标矩阵、客户结构、获客成本气泡图和维度对比。当前全部为演示数据，不代表招商蛇口实际经营情况。

## 安装与运行

```bash
npm install
npm run dev
```

访问终端打印的本地地址，默认 `http://127.0.0.1:5173`。

```bash
npm run build       # TypeScript 严格检查及生产构建
npm run preview     # 预览 dist
npm run lint        # ESLint 检查
npm test            # 核心数据口径和筛选计算验证
npm run format      # 格式化源码
npm run export:mocks # 生成渠道字典和同比样例 JSON
```

当前运行环境 Node.js 16.20.2；因此锁定了支持该环境的 Vite 4 与检查工具。建议在维护时迁移到受支持的 Node.js LTS，并配套升级构建工具。安装时请保留 package-lock.json。

## 页面与交互

- `/marketing-analysis`：默认首页，经营指标卡 → 营销经营与转化分析 → 渠道结构与客户漏斗 → 效率指标和三列图表 → 项目业绩明细，连续展示。
- `/multi-analysis`：矩阵行列维度切换、指标选择、客户结构切换、成本转化散点图、多维趋势与明细。
- `/multi-analysis-2`：渠道、项目、顾问三个量效九宫格，共用顶部筛选；切换同比/环比，可调整平稳区间和最少签约套数，支持分区筛选、气泡选中、明细下钻、CSV/PNG 导出。
- 共用期间、组织、区域、项目筛选，城市、渠道、客群在“更多条件”抽屉中，渠道支持“大类 → 供应商 / 平台 → 细分触点”三级选择。点击“查询”后应用，切换页面保留条件；刷新浏览器后恢复默认。
- 点击指标、排名、气泡、矩阵或明细行打开明细抽屉，关闭或“返回上一级”保留原筛选。
- 图例可切换系列；图表右上角可重置或下载 PNG；表格和报表导出 UTF-8 BOM CSV，可用 Excel 打开。
- 列排序、表格内搜索、分页、固定首列、汇总行与空数据状态。
- 首次加载骨架屏，查询时保留原数据并显示 loading；接口失败可重试，403 显示无权限；断网时显示提示。

## 数据口径

模拟数据位于 `src/mocks/data.ts`，不同项目与渠道使用确定性增长和费用变化系数，供九宫格呈现不同量效方向；各页面共享同一组数据。包含 2025、2026 两年，8 个项目、7 个渠道大类、27 个二级对象、40 个末级触点和 3 种客群的月度记录，共 23,040 条末级事实。默认期间为 2026 年 1–9 月。样例项目名仅作为演示标签。所有金额和费用为万元，指标卡金额转换为亿元，获客成本转换为元。

- 签约转化率 = 签约套数 / 线索组数 × 100%。样例数据以每个成交客户签约一套进行模拟。
- 目标完成率 = 签约金额 / 销售目标 × 100%。目标按项目、月份、渠道和客群分摊，汇总时只加总相应切片。
- 获客成本 = 营销费用 × 10000 / 签约套数；投入产出比 = 签约金额 / 营销费用。
- 同比比较上年同期间，环比比较前一个等长期间。例如 1–9 月的环比为上年 4–12 月。比较期间没有基数时显示“无可比数据”。
- 比率和成本均使用加总后的分子、分母计算，不直接平均各行比率。分母为零时返回 0。
- 签约回款比只是回款金额与签约金额之比，不代表逐单回款率。
- 客户按项目、渠道、客群内去重，跨项目可能重复。明细提供客群级记录，不含个人客户信息；抽屉预览前 100 条，导出提供全部。
- 全局签约口径为当前唯一支持口径；面积段和业态是演示客群的映射，不代表实际客户统计。

## 九宫格口径

- 渠道九宫格移除层级下拉框，默认展示供应商/平台等二级对象；七色图例对应七个渠道大类。点击图例只展示该大类的细分气泡，再次点击、选择“全部渠道”或“返回全部渠道”恢复；各渠道颜色固定。末级触点仍可通过顶部渠道树筛选。
- 渠道 / 项目：X 为签约套数增长率，Y 为单套获客成本变化率，右下方表示增量降本。
- 顾问：X 为签约套数增长率，Y 为到访转签约率的百分点差，右上方表示增量提效。
- 气泡面积对应签约金额，颜色分别表示渠道类型、项目区域、顾问所属项目。极小气泡保留最小可点击直径。
- 默认平稳区间为 X ±5%、获客成本 ±3%、顾问转化率 ±3 个百分点；落在分界线上归入平稳区。这些是可调演示参数。
- 任一期间签约少于 10 套、比较基数为 0 或无期间数据的对象列为不可比，不绘制无穷大变化率；可点击不可比对象数查看原因。切换同比/环比后重新计算比较期。
- 顾问数据来自 `src/mocks/advisors.ts`，每项目虚构 4 人，按月度渠道/客群切片分配，保留项目金额、费用和漏斗数量合计。真实接口模式不自动虚构顾问；需提供可选的 `advisorId`、`advisor` 字段及顾问粒度事实记录。
- 新页面计算在 `src/utils/nineGrid.ts`，图表配置在 `src/charts/options/nineGrid.ts`。`npm test` 覆盖分区边界、百分点口径、基数、分配守恒及 ECharts SVG 渲染。

## 替换真实接口

1. 将 `.env.example` 复制为 `.env.local`，设置 `VITE_USE_MOCK=false` 与 `VITE_API_BASE_URL`，重新启动。
2. 修改 `src/api/dashboard.ts` 的 `GET /marketing/dashboard` 与 `mapRecord`，将后端字段转成 `MarketingPerformanceMetric`。返回 `{ code: 0, data: [...], message: 'ok', updatedAt: '...' }`。
3. 按 `src/types/index.ts` 提供字段（渠道层级包含 `channelObject` / `channelObjectId` / `channelDetail` / `channelDetailId`，每笔只提供末级事实），统一万元、月份 `YYYY-MM` 与数字类型。同比需要后端提供上年数据，环比需要前一个等长期间数据。
4. 接口返回完整授权分析范围内的数据供当前前端聚合；大数据量场景应改为服务端筛选聚合、分页和权限校验。页面组件不直接拼接 URL。
5. 在 Axios client 添加实际认证与统一响应处理；后端应对数据范围和导出执行权限校验。

## 视觉与部署

本次按参考站点 `https://ops-demo-2026.pages.dev/` 实际 HTML、CSS 与初始化脚本重新对齐。参考页虽保留 `.side` 样式，但实际主体 DOM 没有侧栏；因此使用**全宽顶部品牌 / 标题 / 横向页面导航**，去除上一版侧栏、面包屑、独立大标题与英文说明条。原提示词中的侧栏描述由本次用户要求以参考页实际结构为准覆盖。

- 顶栏 72px，白底，30px 水平内边距，28px 标题，15px 导航和 3px 蓝色选中下划线。
- 内容区 25px / 30px；筛选区 13px / 15px，标签与控件横排，右侧浅蓝更新时间标签，滚动时在 72px 顶栏下吸顶。
- 保留本项目要求的四张营销指标卡，采用参考页的 32px 图标块、蓝色核心值和浅底对比标签。
- 营销页使用参考页“左侧指标拆解 + 右侧趋势”“结构图与明细 + 转化分析”“三列辅助分析”层级，保留招商蛇口营销业务与原有数据接口。
- 页面背景 `#F4F7FB`、主色 `#2873ED`、边框 `#E2E8F0`、9px 面板圆角；无额外装饰区。
- Element Plus 负责全部表单、表格、抽屉与状态组件；当前交互无需额外引入 Ant Design Vue。品牌区域为文字与 CSS 占位标识，可换正式授权 logo，未挪用参考站点的中外运标识。

1280、1440、1920px 使用相同的全宽桌面框架；1250 / 1180 / 1100 / 1000 / 650px 下逐级调整分析列数和筛选布局。当前环境没有可用浏览器，已完成源码对照、严格类型检查、生产构建和数据计算测试，尚未完成真实浏览器截图验收。“材料”目录保留在本地，不随代码提交。

“材料”、`node_modules`、`dist` 和本地 `.env` 文件由 `.gitignore` 排除。`npm run export:mocks` 会自动创建本地“材料”目录并生成字典及样例 JSON。

生产文件在 `dist/`，静态服务器需将业务路由回退到 `index.html`。此交付为本地项目，未发布外网。
